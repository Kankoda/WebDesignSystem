# About

This repository contains the design system for the [Kankoda website][Website] and all the company's product sites.

Run the `sync-to` script to sync the content to another folder. This will replace that folder's version of the design system with this one. 

Syncing will copy two `sync-from` and `serve` scripts, where `sync` will just call this script from the target folder, and `serve` stars the Jekyll website.

[Website]: https://kankoda.com
